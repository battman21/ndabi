# AGENTS.md

Instructions for coding agents in this repository.

## Repository custody

This repository is the canonical source for NDABI protocols, implementations, adapters, campaign specifications, and benchmark evidence.
Other projects must consume NDABI as a dependency or implement a documented integration boundary.
Do not copy or maintain NDABI source or specifications in Onlife or another repository.
Keep consumer-specific integration code in the consumer repository.

## Tests

Run only the minimum test set necessary to prove the requested change.
Run a larger test suite only when the user explicitly requests it.
